# nemo-anha4-iceberg-meltwater-parameterization
Analysis and post-processing code for comparing two iceberg meltwater release parameterizations in NEMO-ICB: meltwater released at the surface (EJM010) and along the iceberg's keel (EJM012). Includes diagnostics for ocean physics and biogeochemistry (BLING) using the ANHA4 configuration, at 1/4 degree of resolution.
